# Curso de JavaScript

Proyecto didáctico para aprender JavaScript aplicado a las interacciones con elementos HTML.

## Objetivo

Mostrar ejemplos prácticos de manipulación del contenido HTML, modificación de atributos y aplicación de estilos CSS mediante JavaScript.

## Funcionalidades de la versión 1.0

- Modificación del contenido HTML mediante JavaScript.
- Modificación de atributos HTML mediante setAttribute().
- Modificación de estilos CSS mediante JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Versión

1.0 - Primera versión estable del proyecto.
